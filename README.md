
Little plugin to make your game expierence better

Well, my first major project is essentially an analogue of the GALA mode found on older car stereos.

The executable file is too large, so I’ll upload it separately somewhere; I’ll provide a guide on what to do next later.


As for the actual guide on how to launch this thing: first, you need to drop the "apps" folder into your Assetto Corsa directory; then, launch the game and check to ensure the settings window has appeared.
<img width="680" height="592" alt="image" src="https://github.com/user-attachments/assets/ce38eb2e-3b63-439b-bfab-fb4300498f46" />

Next, you need to launch the bridge. You can do this either via the .exe file or—if you're a savvy user :)
Via the project file (which is also included). Upon successful launch, it should look like this:
<img width="1728" height="955" alt="image" src="https://github.com/user-attachments/assets/e1e2c46e-3290-4799-86dc-56949374eb95" />
Link to exe-file: https://drive.google.com/drive/folders/1t2zZ00ZbkGE-vBTSVBX33rvAaHJxGA6k?usp=drive_link
That’s pretty much it; from here, you can play around with the sound settings. 
My advice for a *Night Runners*-style feel is to set the speed mapping to 80% and the throttle mapping to 20%. Remember, this program was made just for fun—if you run into any bugs, please let us know so we can try to fix them. 

Enjoy the game!
